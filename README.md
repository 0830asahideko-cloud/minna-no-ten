# みんなの〇〇展 — 第1段階

既存の6つのHTML画面を使う、ブラウザー内で完結する展覧会アプリです。

## 起動

フォルダーを静的HTTPサーバーで配信して `index.html` を開きます。例：Pythonがある環境では `python3 -m http.server 8000 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8000` へアクセスします。HTMLの直接起動（file://）では、ブラウザーによって画面間のlocalStorage共有が保証されません。

## 使い方

1. 「＋」から展覧会のタイトル・説明を入力。
2. 「作品を追加」、または「写真・動画から追加」。最大30点、文章だけの作品も可。
3. 作品ごとにタイトル・文章・写真または動画を設定。「↑ 前へ」「↓ 後へ」で順番を変更。削除やメディア差し替えも可能。
4. 「展覧会をプレビュー」で全作品を順に確認し、「編集に戻る」で続行。
5. 「公開する」で自分の展示室に追加。「入場する」で鑑賞。

下書きは1件を自動保存し、公開済みの展覧会は複数保存します。公開には展覧会名、各作品のタイトル、および各作品の文章かメディアが必要です。プレビューでは未完成の作品も確認できます。

## 保存と制限

- `minna-exhibitions-v1` の単一localStorageキーに、バージョン・展覧会一覧・下書き・作品別の共感とコメント・来場記録をJSON保存します。公開は下書きの移動と一覧への追加を1回の書き込みで行います。
- メディアはData URLとして保存。写真は長辺1280px以内のJPEGに変換（透過は白背景、アニメーションは静止画）。元写真は25MBまで、動画は1本1MBまでです。
- localStorageの容量はブラウザー依存です。30作品未満でも容量上限に達することがあります。保存失敗時はエラーを表示し、以前保存したデータを維持します。未保存の編集は画面に残るため、メディアを小さくするか外して再保存できます。
- 同じブラウザー・同じURLのオリジンでのみ利用できます。別端末との共有、他者への公開、ログイン、サーバーへのアップロードはまだありません。サイトデータを消去すると展示も消えます。
- 自作展示の来場者はこのブラウザーを1人として数えます。来場記録には最新の入場日時を保持し、プレビューは含めません。既存のおすすめはサンプルです。
- 旧 `myExTitle` / `myExCount` は消さず、以前のタイトルがある場合は展示室に案内を表示します。旧実装で未保存だった写真・動画は復元できません。

## ファイルと検証

- `styles.css`：既存6画面の共通スタイル、スマートフォン対応。
- `storage.js`：保存モデル、検証、公開、並べ替え。
- `app.js`：6画面の操作、メディア読み込み、プレビュー、鑑賞。
- `tests/storage.test.cjs`：Node.jsで `node --test tests/storage.test.cjs`。複数展示・30作品上限・保存容量不足・共感とコメントの保存・壊れた保存データを検証します。
